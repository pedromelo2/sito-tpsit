# Esempi guidati del modulo M1

Documenti Markdown costruiti a lezione insieme alla classe, nell'ordine in cui compaiono nella
dispensa `01_Dispensa.md`. Non contengono HTML: il modulo M1 è solo Markdown.

| File | Contenuto | Lezione |
|---|---|---|
| `01_Appunti_Git/Appunti_Git.md` | documento che introduce progressivamente la sintassi: titoli, paragrafi, enfasi, elenchi, collegamenti, immagine, codice in linea e blocchi di codice, citazione, riga orizzontale | prima |
| `01_Appunti_Git/ciclo-git.svg` | immagine richiamata dagli appunti, con lo schema del ciclo modifica, `git add`, `git commit`, `git push` | prima |
| `02_README_esempio.md` | modello di file di descrizione di un progetto, con tabella e caselle di spunta | seconda |

## Come si aprono

I file `.md` si aprono in Visual Studio Code e si leggono nella loro forma definitiva con
l'anteprima: `Ctrl+Shift+V` per la scheda a tutta larghezza, `Ctrl+K` seguito da `V` per
l'anteprima affiancata al testo. Nessuno dei due file richiede la rete.

Per vedere come gli stessi documenti vengono resi da GitHub, si copiano nel proprio repository,
si eseguono `git add`, `git commit` e `git push` e si aprono dalla pagina del repository. Il
confronto fra le due rese è parte dell'esercizio 8.

Il file `ciclo-git.svg` si apre anche da solo con un doppio clic: il browser lo mostra come
un'immagine.

## Avvertenza sul file 02_README_esempio.md

È il file di descrizione di un repository immaginario, `tpsit-3bi-bianchi`, di un'altrettanto
immaginaria studentessa Marta Bianchi. L'indirizzo di GitHub Pages e i comandi `git clone` che
vi compaiono si riferiscono a quel repository e non funzionano così come sono: vanno adattati
al proprio, che è il primo lavoro da fare nell'esercizio 5. Le cartelle elencate nella tabella
descrivono un'organizzazione plausibile a fine anno, non il contenuto attuale del repository.

Il file va letto domandandosi, per ciascuna sezione, a quale domanda del lettore stia
rispondendo.
